# 论坛UI重设计方案

参考：https://meta.discourse.org/ （实际主题列表）；桌面左侧导航、中央列表/阅读区，移动端单列导航。沿用聊天现有字体和颜色体系，论坛采用白底、细分隔线、明确文字层级，不使用大面积圆角表单卡片。

## 页面拆分

1. 主题首页：左栏「所有主题、版块、草稿」，主栏搜索、版块筛选、新主题按钮及紧凑列表。列表只显示标题、版块、署名、真实存在的分支状态；不伪造浏览量、热度和时间。
2. 帖子详情：面包屑、标题、作者及正文、顺序回复。正文优先；历史/对照、举报、管理动作放每帖更多菜单。正文副本说明按需展开。
3. 发布/编辑：独立编辑视图，返回来源页面；标题、正文、附件、发布/保存草稿，不与主题列表混排。未提交输入在导航时保留。
4. 网络连接：独立页面，显示在线状态、连接节点和复制当前入口。首页仅保留简短连接状态入口。
5. 管理后台：管理员专属入口，分成员、版块、举报三页；历史检查点置于管理操作，不进入普通读帖页面。
6. 首次加入：先选加入已有论坛或创建论坛，再显示对应表单；公开身份按申请步骤展示。

## 布局与交互

- 桌面约200px左栏，主内容最大960px，正文最大760px；手机隐藏侧栏，改紧凑导航，触控区至少48px。
- 主题列表和帖子详情使用同一论坛顶栏；论坛内不重复展示整套聊天大标题。
- 普通状态不用常驻大横幅；错误保留明确的重试入口。管理表单不出现在普通主题浏览中。
- 保留现有DOM入口与受限原生接口，重构前端导航及排版，不修改签名、准入或文件协议。

## 实施与验收

先完成前端页面与导航，再适配主题/草稿/连接/管理操作及恢复，最后更新替身测试并做原生实际截图。覆盖桌面1000px、手机320/390px，返回路径、取消编辑、草稿恢复、权限可见性、锁定清理及已有聊天回归。真实原生截图用于验收，不以布局测试代替视觉检查。

审批后实施；本阶段未改产品代码。

## 获批迁移基准

用户已批准 `design/forum-prototype/index.html`，要求原封迁移。基准提交 `b159a20`，包括后来确认的社区切换浮层和昵称入口。产品接入采用同一CSS数值与布局结构，不另行设计；示例数据替换成经验证的真实社区数据。列表中没有来源的时间、浏览量等不制造数值。

用户确认的层级：网络 → 社区 → 版块/主题/成员/管理。任何成员可以创建自己的独立社区并成为该社区管理员；社区准入材料不等于向成员分发管理员或个人身份私钥。昵称由本人签署，不参与权限判定。

实施分工：布局/CSS、页面导航与功能接线、社区隔离与昵称三路并行；仅使用用户指定的gpt-6.1-sol。最终需分别记录浏览器布局/导航测试、Rust测试、构建和实际窗口验证，未跑部分不称通过。

## 实施与验收结果

## 用户反馈后的对齐修正（最终候选9f5490f）

此前“原样迁移”的结论不充分：网络页残留旧details表单、成员页直接展示公钥、详情页重复显示签名/hash/副本。现在按用户要求修正软件，而不只修改原型。

- 网络页回归原型两卡；复制入口成功不展示原码，失败提供同风格手动复制dialog。
- 成员紧凑行；公钥/吊销在身份dialog，历史检查点在高级管理dialog；均使用原型配色/卡片/按钮。
- 详情默认作者/正文/附件/回复；签名与版本、对照、副本、管理均在•••菜单或dialog；举报表单也统一样式。后台同步不自动关闭举报或丢输入。
- 隔离登录页eyebrow遗留的21px上边距与字距，恢复论坛标题位置；手机原型与产品触控区统一48px。
- 前轮AI生成的macOS图标已废弃。icons/logo-source.png保持原图，scripts/macos-icon.swift使用Apple AppKit自带roundedRect裁剪，保留透明安全区，再用Tauri CLI生成icns；无生成阴影或随机杂点。不声称使用了未安装的Icon Composer。

验证：9组浏览器功能回归通过（含举报失败输入、后台同步保留表单）。785/1000/390px分别对照原型的网络/成员/详情截图，卡片padding/radius及标题top位置断言通过；真实内容不同不捏造时间、昵称或计数。对照脚本与截图在target/qa/compare-ui.cjs、compare-thread.cjs及reference/product-*.png。

实际原生Mac最终9f5490f测试窗口已解锁旧库，默认详情不显示hash/副本行，•••可打开真实签名/版本/保存状态dialog，关闭后返回干净阅读页。实际截图target/qa/thread-final-native.png；网络/管理此前原生截图strict-network-native.png、strict-members-native.png，最终额外样式隔离由同视口检查覆盖，不将旧截图说成全部最终源码重测。
