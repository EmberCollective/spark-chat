## 本人全平台测试顺序

建议各端新建独立测试身份，昵称区分“Mac测试”“Windows测试”“Android测试”。先备份已有钥匙和库；不要让不同端共用同一身份私钥，也不要混用旧论坛预览端，新昵称记录需要同批版本。

1. 安装、创建身份、选择钥匙文件；锁定后重新选择已有文件解锁。确认钥匙文件非空。Windows核对中文与WebView2，Android核对系统文件选择器返回及软键盘。
2. Mac或骨干网可入站端创建私聊，Windows/Android分别主动连接。三端文字、图片粘贴/预览/另存为、普通文件收发与切换会话不串内容。论坛连接码与私聊连接码不能混用。
3. 建社区→复制受邀者公开身份→管理员批准→受邀端导入对应材料→用当前社区入口连网。查看版块、发帖、回复、编辑、附件、副本状态；普通成员看不到管理入口。
4. 创建第二社区，切换检查成员/权限/帖子/昵称互相隔离。当前实现只有选中的社区在线提供服务，切换后旧社区数据保留，但不继续后台服务。
5. 先使其他节点实际取得正文/附件，再退出原作者或管理员，核对已有副本可读。各端短暂断网编辑同帖，再联网检查版本保留和冲突处理；断电换IP后旧入口失效需获取新入口，不把无结果等同全网不存在。
6. 核对菜单中的历史/签名/副本、举报重试、管理员锁帖/隐藏/吊销；再锁定/重启，检查旧库、草稿、昵称恢复。Android Activity重建与系统杀进程恢复分开记录。

测试记录请注明平台/系统版本、安装包SHA、操作、实际结果及截图；任一端未测就保留未测，不以编译成功替代运行。
