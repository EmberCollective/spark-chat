## libp2p 0.56 踩坑记录（改 net.rs 必读）

- Codec trait：`#[async_trait]` 宏 + `futures::io` 的 AsyncRead/Write（不是 tokio::io）
- `with_tcp` 第一个参数是 `tcp::Config::default()`（不是 Transport 构造函数）
- `Message::Request { request, channel, .. }` 内含 `request_id`，模式匹配要 `..`
- `RREvent::Message` 的字段叫 `peer`（不是 `peer_id`）
- `Visuals` 无 `extreme_bg`（egui 0.31），用 `code_bg_color`；`ctx.time()` 不存在，用 `ctx.input(|i| i.time)`
- 连接码是 base64url **大小写敏感**，容错清洗不得动大小写
- vault 的 `ed25519_seed()` 返回的数组：libp2p-identity 会 zeroize AsMut 输入，传副本
